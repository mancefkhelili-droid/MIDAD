مِداد — دعم مزوّدي الذكاء الاصطناعي ومساهمات الفريق

ما تغيّر في الملفات:
1) أضيف اختيار نوع API: OpenAI Responses API، وOpenAI-compatible Chat Completions، وAnthropic Messages API، وGoogle Gemini API.
2) يمكن ضبط مفتاح API ورابط API الأساسي واسم النموذج. يدعم نمط Chat Completions مزوّدين شائعين مثل OpenRouter وGroq وDeepSeek وTogether وMistral عندما يوفّرون واجهة متوافقة. ليس كل مفتاح صالحًا لكل مزوّد أو نموذج؛ اختر النمط الصحيح حسب وثائق المزوّد.
3) دعم PDF والصور: Responses وAnthropic وGemini؛ أما نمط Chat Completions في هذا الإصدار فيقبل الصور ولا يقبل PDF.
4) المفتاح لا يُخزّن في قاعدة بيانات مِداد. خيار التذكر يحفظه في localStorage على هذا الجهاز فقط؛ لا تستخدمه على جهاز مشترك.
5) أزيل شرط 10 أوراق من دعوات الفريق، مع بقاء حد الفريق ومحاولات رمز الدعوة. لم نغيّر قواعد أهلية الاشتراك العامة.
6) مساهمة من محفظة العضو إلى صندوق الفريق بمبالغ صحيحة بالدينار، مع منع التكرار باستخدام request_id وسجلّ في محفظة العضو وسجل الفريق. هدف الجمع يحدده صاحب الفريق.
7) قاعدة بيانات Supabase: طُبّق الترحيل على المشروع الإنتاجي، ثم أُعيدت قواعد أهلية الاشتراك العامة إلى سلوكها السابق. تحقّقنا من وجود عمود هدف الفريق ودوال RPC الأساسية.

الملفات:
- index.html / app.js / styles.css: واجهة الموقع.
- supabase/functions/medad-ai-document/index.ts: وظيفة Edge Function متعددة أنماط API.
- 20261012_medad_byo_api_team_contributions.sql: SQL migration المطابق لبنية محفظة مِداد الحالية (الرصيد وسجل المحفظة بالدينار الصحيح).

ما بقي قبل التشغيل على الموقع:
- استبدال ملفات الواجهة في مستودع Vercel ونشرها؛ لم أنشر Vercel من هنا.
- نشر Edge Function باسم medad-ai-document مع Verify JWT مفعّلًا. لم أنشر الوظيفة بعد.
- الاختبار الحقيقي يحتاج مفتاحًا صالحًا من المزوّد ونموذجًا متاحًا في حسابه؛ لم أرسل طلبًا مدفوعًا إلى أي مزوّد.
- بعد النشر، اختبر نصًا عاديًا وصورة وPDF (لكل نمط يدعم المرفق) ومساهمة بين حسابين.

ملاحظات:
- عنوان API يجب أن يكون HTTPS عامًا. أدخل عنوان الأساس لا مسار العملية النهائي: مثل https://api.openai.com/v1 أو https://api.anthropic.com/v1.
- Chat Completions غالبًا يستخدم /chat/completions، وAnthropic يستخدم /messages، وGemini يستخدم /models/{model}:generateContent، وResponses يستخدم /responses.
- صندوق الفريق يجمع الرصيد؛ تفعيل الاشتراك يتم عبر وظيفة medad_team_buy_plan الموجودة أصلًا في قاعدة البيانات، ولا يتم الشراء تلقائيًا لمجرد المساهمة.
